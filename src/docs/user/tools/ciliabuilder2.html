Tool: CiliaBuilder2

The CiliaBuilder2 Tool is a ChimeraX package used to build parametric cilia and centriole model from maps, PDB and GLB files.

The primary functions of the tool are based on 3 action:

  • Build:

    Generates a parametric particle list (STAR format) of a cilium or centriole. This tab allows the user to build doublet/triplet, central pair, membrane and intraflagellar transport (IFT) trains.

  • Attachment:

    Attaches a map, a PDB or a 3D object to the parametric particle list. It is possible to tune the rotation of the map and center of rotation.

  • Save/Load:

    Provides a way to export the session into JSON format and load the JSON file to restore the session. Also, it allows export the particle list into a STAR file. In addition, CiliaBuilder2 can also import STAR file generated from other programs to build custom geometries.
