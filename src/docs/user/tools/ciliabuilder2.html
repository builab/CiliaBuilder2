CiliaBuilder2

CiliaBuilder2 builds STAR-guided cilia geometry and places maps or models on STAR points in UCSF ChimeraX. Open it from Tools > Higher-Order Structure > CiliaBuilder2, or enter cbui.

Quick start

  1. In Build > Microtubules, set the length, number of doublets, radius, and periodicity, then click Build microtubules.
  2. Open a source map or model in ChimeraX. Supported sources include MRC maps, STL, GLB/GLTF, PDB, and mmCIF models.
  3. In Attach > Attachment, choose the STAR model and Map model, then click Attach selected STAR + map.
  4. Use Save/Load > Save session JSON to save the CiliaBuilder2 setup.

Build

Lengths, radii, spacing, and axial offsets use angstroms; angles use degrees.

  • Microtubules: the default layout uses length 9000, nine doublets, radius 960, and periodicity 1000. Twist per layer changes particle orientation at successive layers without moving the filament around the ring. Z offset moves the filament axially. Random shifts whole filaments in Z.
  • Continue microtubules: select a source in Continue from STAR. The continuation is a new segment model; the source remains available.
  • Substitute filament: pick a displayed STAR point in the temporary window, edit the replacement values, confirm the edit with Enter or focus loss, then apply. The replaced filament is separated into its own STAR model.
  • Central Pair: choose Singlet line or C1 + C2 lines. The latter creates separate C1 and C2 models at minus and plus half the C1/C2 distance, so they can use different attachments.
  • Membrane: set length, radius, thickness, axial offset, and distortion. Radius is the cylinder radius. Tip dome cap adds a distal dome.
  • IFT: choose Train to build repeating placements on a target STAR microtubule, or Pick STAR point to place IFT from a clicked STAR point. Both modes offer anterograde and retrograde types.

Attachment

Attachment Z offset (deg) rotates attached geometry about each filament's own line while keeping STAR centers fixed. Attachment Y rotation (deg) adjusts local model orientation. The optional Advanced options checkbox applies a 90-degree clockwise local Y rotation before that adjustment.

After attachment, the source is archived under CiliaBuilder2 > Maps/Models for reuse and the used STAR is usually hidden. STAR particles, membranes, and generated drawing guides are excluded from the source selector.

For a GLB exported from a volume, use save test.glb models #1 center false with CiliaBuilder2 running. Replace #1 with the map ID. The export preserves the volume's grid-center attachment pivot, so the map and GLB overlap on identical STAR placements. For an older GLB without this metadata, keep its matching original map open once; session JSON retains the recovered center. Ordinary meshes still use their own geometry centers.

Use ChimeraX clip front and clip back on attached maps and models. Session JSON saves the scene cut planes and restores them after rebuilding attachments and applying view orient. clip off and per-model clip model #... false settings are preserved. Older JSON files need to be saved again after setting the cuts. Camera-relative near/far planes are not part of this scene-cut state.

Geometric drawing

Under Attach > Geometric drawing, choose Point, Sphere, Cylinder, Curve, or Line and select Draw on model. Start drawing, then click on the model. Point and Sphere need one point; Cylinder needs two. Curve and Line use No. of markers and Tube radius; primitives use Primitive radius. The result appears after the required number of points is placed.

Choose the result in Drawing model and click Save drawing as GLB. The saved GLB is reopened and selected as an attachable source.

Save, load, and undo

Load STAR file imports external STAR placements. Export STAR file writes the current rows of the selected Export STAR model, including edits made after import.

Save session JSON and Load session JSON preserve CiliaBuilder2 models, attachments, colors, and UI settings. File-backed GLB/GLTF sources are referenced at their original paths without exporting additional copies. A compressed name.glb.gz displays as name.glb in Models, but its saved path still refers to the original compressed file. Keep the original sources accessible and keep any copied STL or in-memory assets with the JSON; loading prompts for a replacement when a source path is missing.

The tool's Undo and Redo buttons cover managed build, attachment, and drawing actions, with up to 30 history steps. Loading a session or STAR file resets this history.
