Installation

Download or clone the source from the CiliaBuilder2 GitHub page, then install it from the ChimeraX command line, giving the path of the downloaded folder:

    devel install /path/to/CiliaBuilder2

If you were given a wheel (.whl) file instead, install it with:

    toolshed install /path/to/ChimeraX_CiliaBuilder2-version-py3-none-any.whl

To replace an older version, uninstall it first:

    toolshed uninstall CiliaBuilder2

Restart ChimeraX, then open the tool from Tools → Higher-Order Structure → CiliaBuilder2 or with the command cbui.

Quick start

  1. In Build → Microtubules, keep the default values and press Build microtubules. A STAR model of nine microtubules appears.
  2. Open a repeating unit aligned along Z, for example a map (open emdb:2132) or a GLB file.
  3. In Attach → Attachment, choose the STAR model and the map, then press Attach selected STAR + map.
  4. Adjust Attachment Z rotation until the repeating units face the cilium centre.
  5. In Save/Load, press Save session JSON to keep your work.

See the CiliaBuilder2 tool page for a description of every option.

Example data

The example folder on GitHub contains ready-to-load sessions and inputs. Load a .json file with Save/Load → Load session JSON.

folder contents
1_chlamySession JSON of a Chlamydomonas cilium (doublets and central pair) built from maps fetched from the EMDB.
2_chlamy_glbSession JSON of the same cilium with anterograde and retrograde IFT trains, built from GLB surfaces (.glb.gz), plus the scripts used to Z-align the IFT maps.
3_sperm_pdbSession JSON of a sperm axoneme built from atomic models fetched from the PDB.
4_centrioleSession JSON of a centriole with proximal, core and distal triplet regions, with the Z-aligned maps, their GLB surfaces and the alignment scripts.
extra_transitionzoneA STAR file describing a transition zone, for use with Load STAR file.
