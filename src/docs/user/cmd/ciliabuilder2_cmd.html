Commands: CiliaBuilder2

CiliaBuilder2 adds the following commands to ChimeraX. Most work is done in the CiliaBuilder2 tool; the commands are useful in scripts (.cxc files) and for quickly building a STAR model without opening the tool.

  • cbui – open the CiliaBuilder2 tool
  • cbstraight – build a ring of microtubules as a STAR model
  • buildcentralpair – build a central-pair STAR model
  • cbopenapr – open a local cellPACK package (experimental)

All lengths are in Ångström and all angles in degrees. Keywords are optional and can be given in any order. STAR models made by commands appear in the model panel and can be used on the Attachment page like models built in the tool. Note that the command defaults are not the same as the defaults in the tool.

Usage: cbui

Opens the CiliaBuilder2 tool. The tool can also be opened from Tools → Higher-Order Structure → CiliaBuilder2.

Usage: cbstraight [ length L ] [ nDoublet N ] [ radius r ] [ spacing d ] [ zOffset z ] [ angleSet angle ] [ doubletOffset angle ] [ twistPerLayer angle ] [ randomSpacing true | false ] [ randomMaxDiff d ] [ randomRange r ] [ showArrows true | false ] [ tomoName name ] [ pixelSize size ] [ openStar true | false ] [ printStar true | false ]

Builds N straight, parallel microtubules evenly spaced on a circle of radius r around the Z axis, each running along +Z, and creates a STAR model named Microtubules STAR n. This is the command equivalent of Build microtubules on the Microtubules tab.

keyword default description
length3000Length of each microtubule along Z.
nDoublet9Number of microtubules in the ring (1–9).
radius960Distance from the Z axis to each microtubule.
spacing1000Distance between consecutive particles along a microtubule (the periodicity).
zOffset0Z position of the first particle.
angleSet0Angle around the Z axis at which the first microtubule is placed; rotates the whole ring.
doubletOffset0Extra in-plane rotation applied to every microtubule about its own axis.
twistPerLayer0Rotation added to each successive particle along a microtubule.
randomSpacingfalseShift each microtubule along Z by a random amount, so neighbouring repeats are not in register.
randomMaxDiff0Largest random shift. 0 (or any value larger than the limit) uses the limit of 0.49 × spacing.
randomRange0Full width of the random shift (shifts fall within ± r/2), capped at spacing. When > 0 it takes precedence over randomMaxDiff. The tool uses this, defaulting to the periodicity.
showArrowsfalseDraw arrows showing the orientation of each particle.
tomoNameTS_001Value written to the rlnTomoName column.
pixelSize1Pixel size (Å) written to the STAR file; coordinates are divided by it.
openStartrueDisplay the particles in the graphics window.
printStarfalseAlso print the STAR file contents to the Log.

Example – a 3 µm axoneme with a 96 nm repeat (actual repeat = 1000 Å):

    cbstraight length 30000 nDoublet 9 radius 960 spacing 1000 showArrows true

Usage: buildcentralpair [ length L ] [ spacing d ] [ zOffset z ] [ xOffset x ] [ tubeId id ] [ randomSpacing true | false ] [ randomMaxDiff d ] [ randomRange r ] [ showArrows true | false ] [ tomoName name ] [ pixelSize size ] [ openStar true | false ] [ printStar true | false ] [ namePrefix text ]

Builds a single straight line of particles parallel to the Z axis for the central pair and creates a STAR model named Central pair STAR n. The Central Pair tab uses the same builder; its C1 + C2 lines mode builds two such lines.

keyword default description
length3000Length of the line along Z.
spacing333Distance between consecutive particles (the periodicity).
zOffset0Z position of the first particle.
xOffset0Shift of the line along X, away from the cilium axis.
tubeId100Value written to the rlnHelicalTubeID column.
randomSpacingfalseShift the whole line along Z by a random amount.
randomMaxDiff0Largest random shift. 0 (or any value larger than the limit) uses the limit of 0.49 × spacing.
randomRange0Full width of the random shift (shifts fall within ± r/2), capped at spacing. When > 0 it takes precedence over randomMaxDiff. The tool uses this, defaulting to the periodicity.
showArrowsfalseDraw arrows showing the orientation of each particle.
tomoNameTS_001Value written to the rlnTomoName column.
pixelSize1Pixel size (Å) written to the STAR file; coordinates are divided by it.
openStartrueDisplay the particles in the graphics window.
printStarfalseAlso print the STAR file contents to the Log.
namePrefixCentral pair STARName given to the new STAR model (followed by a number).

Example – a central pair matching the axoneme above with 32 nm repeat (actual repeat = 333 Å):

    buildcentralpair length 30000 spacing 333

Usage: cbopenapr filename [ name text ]

Opens a local cellPACK package (an .apr.json file, or an exported recipe.json / ciliabuilder_manifest.json) and adds it to the CiliaBuilder2 models. name sets the name of the opened model. cellPACK support is experimental and is not shown in the tool at present.

Both cbstraight and buildcentralpair also accept a starFormat keyword, which is currently ignored.
