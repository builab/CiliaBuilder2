CiliaBuilder2 User Guide

CiliaBuilder2 is an open-source ChimeraX bundle for building and visualizing parametric models of cilia and centrioles. It generates STAR particle lists for the axoneme and its associated structures, then places density maps, atomic models (PDB/mmCIF) or 3D objects (GLB) on every particle to assemble a complete model.

Open the tool from the menu Tools → Higher-Order Structure → CiliaBuilder2, or with the command cbui.
