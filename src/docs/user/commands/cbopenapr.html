Command: cbopenapr

cbopenapr file [name model-name]

Open a local cellPACK-style package and group the loaded models under CiliaBuilder2 > Maps/Models. The required file can be an APR results file (*.apr.json), a CiliaBuilder2 ciliabuilder_manifest.json, or its exported recipe.json. Keep the package's referenced assets and directory structure together.

The optional name keyword overrides the model name. Quote paths and names containing spaces.

cbopenapr "/path/to/package/ciliabuilder_manifest.json" name "Cilium package"

The cellPACK load and export buttons are currently hidden in the CiliaBuilder2 tool; this command provides the local package-loading entry point. Use Load session JSON in the tool for CiliaBuilder2 session JSON files.
