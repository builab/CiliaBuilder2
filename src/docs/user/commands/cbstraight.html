Command: cbstraight

cbstraight [keyword value ...]

Build an outer microtubule STAR model under CiliaBuilder2 > STAR Models. All arguments are optional keywords. Lengths use angstroms and angles use degrees. The command defaults below differ from some startup values in the graphical tool.

KeywordDefaultMeaning
length9000Axial length.
nDoublet9Number of filaments, limited to 1–9.
radius700Radius of the filament ring.
spacing960Positive axial periodicity.
zOffset0Starting axial offset.
angleSet0Rotation of the ring layout.
doubletOffset0Base particle orientation offset, in degrees.
twistPerLayer0Additional local rotation at each successive axial layer; filament centers remain fixed in X/Y.
randomSpacingfalseRandomly shift each whole filament in Z.
randomMaxDiff0Maximum random shift; zero uses 0.49 times spacing. Larger values are capped at that limit.
showArrowsfalseDisplay particle orientation arrows.
tomoNameTS_001STAR tomogram name.
pixelSize1Positive angstroms per pixel; STAR coordinates are stored in pixels.
openStartrueRender the generated STAR points and orient the view. False still creates a model containing the rows.
starFormatrelionRetained compatibility argument; output uses RELION-style STAR rows.
printStarfalsePrint STAR text to the ChimeraX Log.

Example matching the tool's default dimensions:

cbstraight length 9000 nDoublet 9 radius 960 spacing 1000 showArrows true

Export the result using Save/Load > Export STAR file in the tool.
