Command: buildcentriole

buildcentriole [keyword value ...]

Build a single central-pair STAR line under CiliaBuilder2 > STAR Models. The command retains its legacy name. For separate C1 and C2 lines, use Build > Central Pair > C1 + C2 lines in the graphical tool.

All arguments are optional keywords. Lengths use angstroms. These command defaults differ from the tool's startup length and periodicity.

KeywordDefaultMeaning
length2000Axial length.
spacing320Positive axial periodicity.
zOffset0Starting axial offset.
xOffset0Position of the line along X.
tubeId100STAR helical tube identifier.
randomSpacingfalseRandomly shift the whole line in Z.
randomMaxDiff0Maximum random shift; zero uses 0.49 times spacing. Larger values are capped at that limit.
showArrowsfalseDisplay particle orientation arrows.
tomoNameTS_001STAR tomogram name.
pixelSize1Positive angstroms per pixel; STAR coordinates are stored in pixels.
openStartrueRender STAR points and orient the view. False still creates a model containing the rows.
starFormatrelionRetained compatibility argument; output uses RELION-style STAR rows.
printStarfalsePrint STAR text to the ChimeraX Log.
namePrefixCentral pair STARModel name prefix; quote values containing spaces.

Example:

buildcentriole length 9000 spacing 333 xOffset -50 namePrefix "C1 STAR"
